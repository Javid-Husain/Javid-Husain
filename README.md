<!-- ------------------------ AEGIS --------------------------- -->

<h3>🛡️ Aegis — AI-Powered Intelligent Agent System</h3>

<p>
  Aegis is an AI agent system I'm currently building to explore how
  Large Language Models can be combined with tools, structured workflows
  and task execution to create practical intelligent systems.
</p>

<p>
  Rather than treating an LLM as only a question-answering model,
  the project focuses on building a system around the model that can
  reason through tasks, interact with tools and execute multi-step workflows.
</p>

<b>Key Areas:</b>

<ul>
  <li>🤖 Large Language Models</li>
  <li>🧠 Agent Architecture</li>
  <li>🔧 Tool Integration</li>
  <li>💬 Prompt Engineering</li>
  <li>🔄 Multi-Step Workflows</li>
  <li>🐍 Python</li>
  <li>🏗️ AI System Design</li>
</ul>

<p>
  <b>Status:</b> 🚧 Currently Under Development
</p>

<br>

<!-- ------------------- EDGE VISION ------------------------- -->

<h3>👁️ Edge Vision System — Intelligent Computer Vision</h3>

<p>
  An AI-based vision system focused on bringing computer vision
  inference closer to the edge while considering the practical
  constraints of real-world deployment.
</p>

<p>
  The project explores the complete pipeline from visual input
  and model inference to efficient deployment on resource-constrained
  edge environments.
</p>

<b>Key Areas:</b>

<ul>
  <li>👁️ Computer Vision</li>
  <li>🧠 Deep Learning</li>
  <li>⚡ Edge AI</li>
  <li>⏱️ Low-Latency Inference</li>
  <li>🔋 Resource-Constrained Computing</li>
  <li>📦 Model Deployment</li>
  <li>🧩 Efficient Inference</li>
</ul>
